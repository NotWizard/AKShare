# CRCL (Circle) 投资论点监控体系

> 论点框架：当前估值 = 利息收入基金价值 + "平台化转型"看涨期权。
> 期权时间窗口：Arc 主网（2026-09-16）后的 2-3 个季度。
> 建立日期：2026-08-20

## 设计原则

1. 宏观定水位（利率、行业总盘），执行定份额（Circle 自身份额与新业务）
2. 领先指标优先：流通量、交易量先行，财报是滞后确认
3. 每项指标必须有：基线、频率、数据源、警报条件
4. 体系必须可证伪：明确论点失效条件

## 决策规则

**黄色警报（单条触发 → 复盘论点）**
- USDC 流通量 YoY <15%
- 非储备收入占比连续两季停滞
- 分发成本率 >60%
- 单次降息 >25bp 且公司无对冲叙事

**红色警报（组合触发 → 论点证伪）**
- 2027 年中：非储备占比 <10% + 流通增速 <10% + 降息继续
- 对应动作：估值锚滑向货币基金侧（$37–50 档逻辑），重新评估持仓

**确认信号（组合出现 → 期权变实值）**
- 非储备占比 >15%
- BlackRock / Visa 链上真实部署
- 流通增速在降息周期守住 20%
- Clarity Act 通过
